Telco Customer Churn Analysis
This project focuses on developing a machine learning model to predict customer churn for a telecommunications company. Customer churn, in this case, refers to customers discontinuing the use of the company's services. By identifying the key factors driving churn and accurately predicting which customers are at risk, the project aims to provide actionable insights that help the company retain its customers and boost loyalty, ultimately supporting revenue growth.

Project Summary
Background:
In the telecommunications sector, retaining existing customers is more cost-effective than acquiring new ones. This project leverages machine learning techniques to uncover the reasons behind customer churn, classify high-risk customers, and recommend strategic actions to minimize customer loss.
Objectives:
•	Primary: Predict customers who are likely to churn.
•	Secondary: Identify the major factors contributing to churn and suggest data-driven strategies to improve customer retention.
Data Description:
The dataset used in this project is divided into three segments:
•	Training Set (3,000 records): Includes customer demographic data, subscription details, monthly charges, tenure, and churn status.
•	Validation Set (2,000 records): Builds upon the training data to refine model performance.
•	Testing Set (2,000 records): Used to evaluate the final model's effectiveness and simulate real-world performance.
These datasets are sourced from multiple locations: a Microsoft SQL Server database, a GitHub repository, and an Excel file hosted on OneDrive.
